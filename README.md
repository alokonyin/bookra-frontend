# Bookra.com Frontend

Next.js frontend for Bookra.com - Online Travel Agency for East Africa

## Getting Started

### Prerequisites
- Node.js 18+ 
- npm or yarn

### Installation

```bash
npm install
```

### Environment Variables

Create a `.env.local` file in the root directory:

```env
NEXT_PUBLIC_API_URL=your_backend_url_here
```

### Development

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser.

## Deployment on Vercel

1. Push code to GitHub
2. Import project to Vercel
3. Add environment variable:
   - `NEXT_PUBLIC_API_URL` - Your Replit backend URL

## Tech Stack

- Next.js 15.5.6
- TypeScript
- Tailwind CSS
